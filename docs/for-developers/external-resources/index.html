External Resources for Developers

The resources below are grouped by what you're trying to do. Each one is free unless noted. If you're new, start with the first item in each group.

Understand the rules​

ResourceUse it for
WCAG 2.2 Quick ReferenceEvery success criterion with techniques and failures. Filter by level and technology.
Understanding WCAG 2.2The intent behind each rule, who it helps, and examples. Read it when a rule is unclear.
WCAG 2.2 (the standard)The normative text, when you need the exact wording.
WebAIM WCAG 2 ChecklistA plain-language version of the rules.

Understand the accessibility tree​

ResourceUse it for
MDN: Accessibility treeA short definition, with links to go deeper.
HTML Accessibility API Mappings (HTML-AAM)Exactly which role and properties the browser gives each HTML element.
Accessible Name and Description ComputationHow the browser decides a control's name: aria-labelledby, aria-label, <label>, content, title, placeholder.
Chrome DevTools: Accessibility featuresHow to inspect the tree, names and contrast in Chrome and Edge.

Build components the right way​

ResourceUse it for
ARIA Authoring Practices Guide (APG)Roles, states and keyboard behavior for tabs, dialogs, menus, comboboxes and more, with working examples.
Using ARIAThe five rules of ARIA. Rule one: use native HTML first.
MDN: AccessibilityReference for every ARIA role and attribute, plus guides.
Inclusive ComponentsLong-form explanations of how to build common components accessibly, and why.
W3C WAI TutorialsStep-by-step guides for forms, tables, images, menus and carousels.

On this site: ARIA Roles and the Accessible Web Development Checklist.

Test your work​

ResourceUse it for
axe-coreThe rules engine behind most scanners. Run it in your test suite.
axe-core for Java (Maven)Bindings for Playwright, Selenium and HtmlUnit.
Playwright: Accessibility testingUsing axe with Playwright, plus aria snapshots.
Testing Library: ByRoleRole-based queries for JavaScript component tests.
Accessibility Insights for WebFree browser extension from Microsoft. FastPass for quick checks, Assessment for a guided WCAG review.
WAVEBrowser extension that shows issues directly on the page.
pa11yCommand-line scanner, easy to add to CI.
IBM Equal Access ToolkitIBM's accessibility checker, as a browser extension and for automation.
WebAIM Contrast CheckerCheck any two colors against WCAG contrast rules.
W3C list of evaluation toolsA searchable list of over 100 tools.

On this site: Test What Scanners Miss explains what each kind of test catches.

Use a screen reader​

ResourceUse it for
NVDAFree screen reader for Windows. Use it with Firefox.
WebAIM: Using NVDA to Evaluate Web AccessibilityThe keys you need, and how to test with it.
VoiceOver User Guide (Mac)Built into macOS; turn it on with Cmd+F5.
WebAIM: Using VoiceOver to Evaluate Web AccessibilityThe Mac equivalent of the NVDA guide.
JAWSWidely used commercial screen reader for Windows (paid; has a demo mode).

Keep learning​

ResourceUse it for
web.dev: Learn AccessibilityA free, structured course from the Chrome team.
W3C WAI: Digital Accessibility FoundationsFree online course from the W3C.
The A11Y ProjectCommunity-driven checklist, articles and resources.
WebAIM articlesIn-depth articles on almost every accessibility topic.
Deque UniversityCourses and references (some free, most paid).

On this site: Communities & Groups and Conferences & Events.

Design accessible APIs and developer tools​

ResourceUse it for
How to design APIs for accessibility (endjin)Naming and documentation choices that help developers who use screen readers.
How to Design More Inclusive APIs (Nordic APIs)Inclusive naming and documentation practices.
API Accessibility: Designing Inclusive Data InterfacesMaking API responses easier to use in accessible apps.
Accessibility APIs and their modern use case for UX (LogRocket)How operating system accessibility APIs connect apps to assistive technology.
The accessibility-first approach (dev.to series)A series of practical articles for front-end developers.

On this site: Accessible API Design for Developers.
